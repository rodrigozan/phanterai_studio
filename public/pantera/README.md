# public/pantera/

PNGs da mascote enviados pelo Rod (fundo transparente). Um arquivo por pose, nomes exatos:

- `feliz.png`
- `triste.png`
- `surpresa.png`
- `comemorando.png`
- `pensando.png`
- `apontando.png`

A pantera nunca é espelhada — o boné tem lado fixo. A pose `apontando` aponta para a
esquerda; posicione o alvo da cena à esquerda dela.
