# Afro WW2 Tales

Canal @AfroWW2Tales. Cada vídeo parte de narração, músicas e imagens prontas (Google Drive); o studio faz validação, sincronização, montagem (ffmpeg), QA e packaging. Sem Remotion nesta marca por enquanto.

- Direção de cada vídeo: `videos/<slug>/BRIEFING.md`
- Mídia: `public/afro-ww2-tales/episodes/<data>/{Narration,Images}` e `public/afro-ww2-tales/musics` (comuns ao canal)
- Trabalho e saídas (fora do git): `out/afro-ww2-tales/<slug>/{input,sync,work,qa}`
- Vídeos: `massaquoi-hamburg` (em produção)
